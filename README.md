On joue en FizzBuzz en enchaînant des appels à “next”.
Le premier doit répondre “1” → ITER 1
Le second doit répondre “2” → ITER 2
Le troisième doit répondre “Fizz” → ITER 3
Le 4e doit répondre “4” → ITER 4
Le 5e doit répondre “Buzz” → ITER 5
Le 7e, 8e, 11e doivent répondre “7” “8” “11” → ITER 5
Le 6e, 12e, 15e doivent répondre “Fizz” → ITER 6
Le 10e, 20e, 50e doivent répondre “Buzz” → ITER 7
Le 15e doit répondre “FizzBuzz” → ITER 8
Les 30 premiers coups doivent produire une partie qui ressemble à : 
“1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz, 16, 17,
Fizz, 19, Buzz, Fizz, 22, 23, Fizz, Buzz, 26, Fizz, 28, 29, FizzBuzz”     → ITER 9
